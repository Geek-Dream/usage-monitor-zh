# Usage Monitor 简体中文汉化工具

非官方简体中文汉化包，基于 [edilsonvilarinho/usage-monitor](https://github.com/edilsonvilarinho/usage-monitor)
`v42.3.0-beta.9`（MIT License）。

这不是完整源码仓库，也不包含编译好的应用；它是一套「把上游源码汉化并重新编译」的工具。

## 说明：本仓库只做汉化

这里**只做简体中文界面本地化，仅此而已**：

- 不修改计费、配额、登录、网络请求等任何功能逻辑；
- 不提供破解、绕过额度、共享账号、伪造数据等任何功能；
- 不收集、不上传任何用户数据；
- 所有功能与上游一致，应用由上游源码编译而来。

本项目为非官方汉化，与上游作者无隶属关系。

## 用法

1. 下载对应版本的上游完整源码，解压后放到本仓库同级的 `源码/` 目录（目录名必须是 `源码`）。
2. 打开 `版本.txt`，改成源码版本号，例如 `42.3.0-beta.9`。
3. 双击 **`一键汉化并构建.command`**。

脚本会：

1. 检测源码是否已汉化；未汉化则套用 `汉化资源/覆盖文件/` 里的汉化文件；
2. 重新生成中文词典（已有文案走本地缓存，新文案联网翻译）；
3. 用 Gradle 编译；
4. 关闭正在运行的应用，把旧应用移到 `备份/`，替换成新构建并打开。

首次双击如果被 macOS 拦截：右键文件 → **打开** → 再点一次「打开」。

## 环境

- macOS
- JDK 17
- Gradle 9.9.1（脚本优先使用 `/tmp/gradle-9.9.1`，没有时使用源码自带的 `gradlew`，首次需联网下载）

## 目录

| 路径 | 作用 |
|---|---|
| `一键汉化并构建.command` | 双击入口 |
| `版本.txt` | 编译时写入应用的版本号 |
| `汉化说明.md` | 中文使用说明 |
| `汉化资源/覆盖文件/` | 117 个汉化后的 Kotlin 源文件 |
| `汉化资源/翻译工具/chinese_ui_translation.py` | 扫描英文文案并生成 `ZhTranslations.kt` |
| `汉化资源/翻译工具/zh-translations.json` | 1345 条中英文翻译缓存 |

## 已知限制

- 汉化文件基于 `42.3.0-beta.9`。更新到更高的上游版本后，如果改动较大，覆盖后可能编译失败；脚本会自动恢复源码，旧应用不会被替换。
- 新出现的文案通过 MyMemory 自动翻译，质量一般；可自行修改 `zh-translations.json` 后重新运行脚本。
- 帮助页里的录屏和截图沿用上游素材，画面中的界面文字可能仍是原语言。
